# CARE-Psy Benchmark Raw Data Policy

This directory is reserved for external benchmark raw files that are obtained from their official sources with license review.

Do not copy training data, RAG chunks, few-shot prompts, or generated candidate outputs into this raw benchmark area.

CARE-Psy Benchmark V1 currently enables only the internally authored normalized files in `evaluation/benchmarks/normalized`. External datasets remain registered but disabled until their official raw files are present and reviewed.
